# 教程 3：助手首次配置与日常使用

**前提**：已经按教程 1、2 完成准备，Proxy Manager 正在运行，并且你手上有：
- 预期出口 IP
- 代理名称（zone）
- 管理端口和代理端口
- Proxy Manager 1.679.135 安装包

## 一、首次配置（只做一次）

打开助手，点 **首次配置向导**，按顺序填写：

| 项目 | 填什么 |
|---|---|
| 1. 独立预期出口 IP | 教程 1 记下的 ISP IP。要从 Bright Data 控制台抄，**不要**把助手检测出来的 IP 当成预期 IP |
| 出口检测服务 HTTPS 地址 | 能直接返回你当前 IP 的网址：返回纯 IP 或 JSON `{"ip": "..."}` 都可以。例如 `https://api.ipify.org`。地址里不能带 `?` 参数 |
| 独立预期区域 | 教程 1 里的代理名称（zone 名） |
| 目标映射要求 | 一般选“明确不需要目标映射” |
| Claude 网页地址 | 保持默认的 `https://claude.ai/` |
| 2. 代理 / 管理端口 | 点 **查找并选择端口**。助手会列出 Proxy Manager 正在监听的端口，请对照 Proxy Manager 界面选对：代理端口如 24000，管理端口如 22999 |
| 3. Chrome 程序（网页端才需要） | 点 **选择已有快捷方式**，选你给 Claude 专用的那个 Chrome 快捷方式，核对程序和配置目录 |
| 4. 最后核验管理器基准 | 点 **选择安装包并核验**，选教程 2 保留的 `luminati-proxy-manager-v1.679.135-setup.exe`，再选 Proxy Manager 的安装文件夹 |

最后点 **保存本机配置**。

> 专用 Chrome：建议给 Claude 单独建一个 Chrome 用户（单独的快捷方式和用户数据目录），并让它通过 Proxy Manager 的代理端口上网。具体方法可以参考 Bright Data 官方的[浏览器扩展说明](https://docs.brightdata.com/proxy-networks/browser-extension/quickstart)。

## 二、用桌面端

1. 主窗口点 **查找桌面端**，选中找到的 Claude 桌面端。
2. 如果 Claude 桌面端已经开着，先**自己正常退出**它。
3. 点 **重新检测**，等各项检查都显示通过。
4. 点 **启动桌面端**，发一条消息，确认能正常收发。

检测结果只在 60 秒内有效，超时后要重新检测才能启动。

## 三、用网页端（带持续监测）

1. 点 **选择本次专用 Chrome**，选中刚才配置的那个专用 Chrome。
2. 点 **重新检测**，检测通过后点 **打开网页端**。
3. 点 **开始监测**，助手会定时核对这个 Chrome 的出口：
   - 出口一旦异常，助手会立刻断开这个 Chrome 的网络，报告里会写明原因；
   - 先排查原因（比如 Proxy Manager 是不是关了、IP 有没有变），再点 **手动复检恢复**。
4. 不用了就点 **停止监测**。

## 四、报告

- **复制报告 / 导出报告**：默认隐藏完整 IP；勾选“报告包含完整 IP”后才会显示完整 IP。
- **查看历史**：保留最近 10 次检测的报告，关闭助手后会清空。

## 避坑提醒

- 任何输入框都**不要**填账号、密码、令牌或聊天内容。配置是明文保存在本机的。
- 换电脑或重装系统后，要按这台电脑的实际情况重新配置。不要直接复制别的电脑的配置文件。
